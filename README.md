## 📚 Unidades del Recorrido
- **Unidad 1:** Introducción al entorno Visual Studio .NET, C# y controles WinForms.
- **Unidad 2:** Almacenamiento dinámico de datos y gestión de memoria.
- **Unidad 3:** Estructuras dinámicas de datos y Listas Enlazadas.
- **Unidad 4:** Algoritmos recursivos y manejo de nodos y punteros.
- **Unidad 5:** Gestión avanzada de archivos y persistencia de datos.
- **Unidad 6:** Paradigmas de programación y autoevaluación.
